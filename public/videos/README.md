# Videos Folder

Place your family video files (.mp4, .webm, .mov) directly in this folder: `public/videos/`

For example:
- `public/videos/vacation-2024.mp4`
- `public/videos/birthday-party.mp4`

Once placed here, you can add them to the library using the **Manage Videos** page in the app, or they will be served at `/videos/vacation-2024.mp4` or through the range-streaming route `/api/stream/vacation-2024.mp4`.
